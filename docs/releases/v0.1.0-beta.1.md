# Big Brother v0.1.0-beta.1

First public preview of the GitHub commit review watcher.

- Watches explicitly configured repositories and branches; reviews each new commit after the initial branch baseline.
- Publishes advisory `big-brother/review` Commit Statuses and optional Prime-approved finding Issues.
- Persists review state in SQLite. Failed reviews use durable exponential retry backoff.
- Runs as a foreground process under systemd or launchd.

Install the attached archive with `scripts/install.sh`, then follow its README for GitHub token permissions and Prime model setup. This preview does not modify watched source code or block merges.

Known limit: reviewer output can require retry when Prime omits evidence references. The retry backoff limits repeated model calls; it does not guarantee a valid model result on the next attempt.
